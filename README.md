# Lasso

An iPhone app for a Cowboy 3 whose battery occasionally drops out mid-ride.
When that happens the bike reboots locked, and the official app's Auto Unlock
does not kick in again. This app keeps a Bluetooth connection to the bike in
the background, notices the drop, and sends the unlock as soon as the bike is
back (within about a second), so you never have to stop and hold the button
in traffic. Tested on a real bike on firmware 4.21.5.

## How it talks to the bike

The bike exposes a lock characteristic (write `01` to unlock, `00` to lock;
it notifies every change), a protobuf dashboard stream (speed, battery,
voltage, ...) while unlocked, and a Nordic UART that carries Modbus RTU frames
to the main PCB (lights, auto-lock, PCB reboot). It requires an authenticated
bond with a 6-digit passkey; iOS stores bonds system-wide, so a phone paired
through the official app needs no code here.

The full byte-level reference, written so it can be implemented on any
platform, is in [docs/protocol.md](docs/protocol.md). Protocol knowledge comes
from [Bronco Unleashed](https://github.com/runerune/BroncoUnleashed),
[Cowboy Untamed](https://github.com/Imaginous/Cowboy_Untamed) and
[cowboyunleashed](https://github.com/mmmago/cowboyunleashed).

## How it decides to unlock

Mode **During a ride** (default): a ride starts when the bike is seen unlocked.
If the link drops and comes back within the reconnect window (60 s) with the
bike locked, that is a reboot, and it gets unlocked. A lock notification within
15 s of the bike moving is treated the same way. A lock at standstill, or a
reconnect after a longer absence, ends the ride and is respected.

Mode **Always** unlocks on every connect. **Off** only logs.

The mechanism (write type, delay, retries, lock polling) can be tuned in
Settings, with presets. Details in [docs/protocol.md](docs/protocol.md#re-unlock-policy).

Everything around connects, disconnects, drops and lock changes is logged
with error codes, link uptime, RSSI, lock state, battery and app state, and
can be shared as a text file from the Log card.

## Build

```sh
brew install xcodegen
cd ios
xcodegen generate
open Lasso.xcodeproj
```

The Xcode project is generated from `ios/project.yml` and not checked in. Run
on a real iPhone to talk to a bike (Bluetooth is not available in the
Simulator). The app icon is drawn by `ios/scripts/make-icon.swift`; from
`ios/`:

```sh
swift scripts/make-icon.swift Resources/Assets.xcassets/AppIcon.appiconset/icon-1024.png
```

## Demo mode and screenshots

Launched with `-demo`, the app shows a fake bike mid-ride with a log of a real
battery drop being fixed, so it can run in the Simulator. `-screen home`,
`log` or `lockscreen` opens that screen directly.

App Store screenshots come from UI tests driving demo mode:

```sh
ios/scripts/screenshots.sh
```

The script writes the captures next to the repository (see the script header)
where a framing step adds captions and device frames.

## Purchases

The open-source build has no paywall. The App Store build is configured with
a RevenueCat key at build time and offers a 7-day trial followed by a one-time
lifetime purchase; without the key every feature is simply on. Manual unlock,
lock, lights and the log are never gated.
